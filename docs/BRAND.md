# DSH Helper · 品牌指南 / Brand guide

## 名称 / Name

- 产品名 / Product: **DSH Helper**。
- 中文名 / Chinese name: **DSH 助手**。
- npm 包 / npm package: **`@liucxu/dsh-helper`**。
- 中文标语：**用量看得见，任务有提醒。**
- English tagline: **Know your usage. Catch every handoff.**

DSH Helper 是 DeepSeek Harness 的独立社区插件，提供供应商余额与额度查询、Token 用量和费用估算、系统通知。与 DeepSeek 无隶属或背书关系。

DSH Helper is an independent community plugin for DeepSeek Harness: provider balances and quotas, token usage and cost estimates, and desktop notifications. It is not affiliated with or endorsed by DeepSeek.

## 图标 / Icon

[主图标 / Primary icon](../icon.svg) 使用 256 × 256 的 SVG 画布：午夜蓝底、银色 H、冰蓝上升连桥与琥珀提醒点。H 对应 Helper，连桥对应用量趋势，提醒点对应需要关注的会话事件。

The icon combines a silver H, an ascending blue bridge, and an amber notification dot on a midnight tile. Use the complete square tile at 24 px or larger, preserve its aspect ratio, and leave clear space around it.
